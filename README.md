# 야간 질주

가족끼리 하는 야간 도심 레이싱 게임이에요.

## 처음 설치 (Windows)

1. 오른쪽 **Releases**에서 가장 최근의 `NightRacer_windows.zip` 을 받아요.
2. 압축을 풀고 `NightRacer.exe` 를 실행해요.
   "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.

## 업데이트

자동이에요. 게임을 켤 때 새 버전이 있으면 알아서 받고 다시 켜져요.

## 온라인으로 같이 하기

방장이 **방 만들기**, 나머지는 방장 주소로 **참가하기**. 자세한 방법은 방장에게 물어보세요.
