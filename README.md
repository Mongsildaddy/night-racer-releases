# Street Zero

공도(Public Road, zero street 아님)에서 진행하는 레이스 게임입니다.
경고: 공도 레이싱은 본인과 타인의 재산 및 생명을 해치는 불법 행위이며, 이 게임은 공도 레이싱을 조장하거나 옹호하지 않습니다.

## 처음 설치 (Windows)

1. 오른쪽 **Releases**에서 가장 최근의 `NightRacer_windows.zip` 을 다운로드합니다.1
2. 압축을 풀고 `NightRacer.exe` 를 실행합니다.
   "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.

## 업데이트

자동 업데이트됩니다. 게임을 켤 때 새 버전이 있으면 알아서 받고 다시 실행됩니다.

## 온라인으로 같이 하기

방장이 **방 만들기**, 나머지는 방장 주소로 **참가하기**. 자세한 방법은 방장에게 키를 받아서 실행합니다.ㄴ=
